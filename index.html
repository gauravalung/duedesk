Connect Claude in 60 seconds

  1. Create your desk and copy your private Connector URL from the dashboard.
  2. In Claude, open Settings → Connectors → Add custom connector, name it "DueDesk" and paste the URL.
  3. In a chat, turn on DueDesk from the tools menu and say "Invoice …". That's it.

Works with Claude Desktop, claude.ai and Claude Code (claude mcp add --transport http duedesk <your URL>).
